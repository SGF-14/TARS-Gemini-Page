BUILT-IN FUNCTIONS — what the robot can actually run

These implementations exist in the page (shown here Python-style for readability). Declare a function with one of these names and the model can trigger it — use them as the pattern for your own.

HOW TO WRITE A FUNCTION
"name"
Required. What the model calls — for the robot use: walk, spinColumns, liftOuterColumns, demo, stop (see BUILT-IN FUNCTIONS in the list view). Any other name is delivered back to the model as "unknown" (useful for experimenting).
"description"
The model reads this to decide when to call the function — write it like an instruction to a colleague.
"parameters"
The arguments, as a schema: "type": "OBJECT" with a "properties" map. Types are UPPERCASE: STRING, INTEGER, NUMBER, BOOLEAN. For lists use "type": "ARRAY" with an "items" schema — that's how spinColumns accepts several columns at once. Describe each property — descriptions steer the model's argument choices.
"required"
Optional list of property names the model must always provide.
no arguments?
Leave "parameters" out entirely (like demo / stop).
